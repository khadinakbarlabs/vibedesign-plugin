# Private Plugin Creator adapter

This adapter is combined with the canonical `plugin/skills/`, resources, public documentation and artwork only when building the private Plugin Creator archive. It supplies the portable manifest and OpenAI skill presentation metadata. The Anthropic manifest and marketplace are excluded from that archive. This folder is not a second skills implementation or an executable plugin.

The service generates its own Codex compatibility manifest. Read back the exact release after a guarded update; do not infer publication or Claude host behavior from private creation.
