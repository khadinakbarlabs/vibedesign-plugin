# Open-source design reference research

Checked October 11, 2026. Stars are observed GitHub API snapshots for these repositories, not quality scores or a claim that every repository in the niche was ranked. General skill/agent repositories have broader audiences than their UI/UX modules.

UI UX Pro Max and Impeccable are the two direct design-focused references examined. The product adds source-linked Actor research, explicit evidence limits, editable UX/specification contracts, offline/import mode, and a connected developer handoff. Upstream executables and agents are excluded. Exact commits and selected file hashes are recorded in RESEARCH-SOURCES.json and the package provenance.

Primary authoring guidance: [native manifest](https://code.claude.com/docs/en/plugins-reference), [directory checks](https://claude.com/docs/plugins/pre-submission-checklist), [directory publishing](https://claude.com/docs/directory/publish), [Apify CLI](https://docs.apify.com/cli/docs/reference), and [WCAG 2.2](https://www.w3.org/WAI/WCAG22/quickref/).
