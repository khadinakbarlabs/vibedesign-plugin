# VibeDesign support

Report reproducible problems through this repository's GitHub Issues: https://github.com/khadinakbarlabs/vibedesign-plugin/issues.

Include the VibeDesign version, host and CLI versions, affected skill, what you expected, and a minimal anonymized example. Keep API tokens, cookies, authentication files, personal reviewer details, raw customer data, and private account URLs out of public issues.

For Actor/source failures, include a sanitized error summary and the Actor/build name. Provide a run identifier only through an appropriate private support channel if requested. This project does not promise a response time or operate a separate support-data service.
