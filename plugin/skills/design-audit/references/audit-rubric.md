# Audit rubric

Evaluate task completion; navigation; content hierarchy; understandable actions; forms and errors; feedback and recovery; component consistency; responsive/long-content behavior; and accessibility.

- Blocker: a required task cannot be completed or creates serious harm/data-loss risk.
- High: a common important task is difficult, misleading, or inaccessible.
- Medium: avoidable friction, inconsistent behavior, or unclear content with a workaround.
- Low: polish or minor inconsistency with limited task impact.

Confidence is a separate field: measured/observed, supported inference, or hypothesis. Never silently promote an inferred issue into a measured failure.

State coverage: which screens, tasks, sizes, states, keyboard/assistive technology paths, and languages were inspected. List important untested paths. A heuristic review is not a usability study or a WCAG certification.
