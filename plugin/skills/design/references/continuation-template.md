# Design continuation

Save this only when another session or person needs to continue the work. Keep it in the user's project, never in the installed plugin. Use local project-relative artifact paths and sanitized summaries; exclude credentials, account details, personal review data, and raw logs.

- Goal and first useful result.
- Accepted scope, constraints, and human decisions.
- Plugin/host edition and relevant project version when known.
- Existing artifact paths and their proposed, implemented, tested, or approved state.
- Checks actually performed, result, and evidence path; label unrun checks.
- Research operation state: not started, running, partial, completed, failed, or unknown. Link the user-controlled operation ledger when one exists; keep sensitive identifiers out of a shared handoff.
- Changed or stale evidence and unresolved dependencies.
- One next action, its completion condition, and any genuinely missing input or authority.

On resume, compare the note with current files and the latest request. The note records observations and decisions; it is not authority for new collection, spending, deployment, or publication.
